Resto Connect is a full-stack Restaurant Management System designed to streamline restaurant operations and enhance the customer experience. Built with a multi-tier architecture, it provides role-based access for Admins, Restaurant Owners, and Customers.

Key Features:
• Admin Web Dashboard – manage restaurant approvals, monitor platform activity, and moderate reviews  
• Owner Web Panel – secure onboarding, menu and table management, and real-time booking tracking  
• Customer Android App – browse restaurants, reserve tables, pre-order meals, and access a seamless mobile experience  

## 🛠️ Tech Stack

- Frontend: React.js  
- Backend: Node.js (Express)  
- Database: MySQL  
- Mobile: Android (Java/Kotlin)  
- Authentication: JWT  
- APIs: REST APIs  

The system is built with a focus on scalability, secure authentication, and efficient API design. Implemented structured workflows and optimized database interactions to ensure smooth booking operations and consistent user experience across platforms.

Resto Connect bridges the gap between restaurants and customers by delivering operational efficiency for owners and a convenient booking experience for users.
